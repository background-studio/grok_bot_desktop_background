# Grok Bot Background Studio v0.3.7

## 修复

- 兼容 Grok Bot 0.57.1 / Electron 42.1.0 关闭主进程 Inspector 启动参数的变化，保留原生标题栏透明效果。
- 启动前备份并校验 EXE，仅临时开启 Inspector fuse；完成内存标题栏补丁后立即关闭回环 Inspector。
- 独立恢复助手在所有 Grok 进程退出后精确还原 EXE；支持 worker 崩溃后的 Inspector 收尾，以及插件下次启动时恢复遗留事务。
- 官方更新导致 EXE 哈希变化时拒绝用旧备份覆盖新版；恢复错误绑定事务，防止过期错误阻断后续启动。
- 修复真实错误被“等待启动”状态覆盖，以及隐藏/最小化窗口中图片解码挂起的问题。

## 重要说明

- 此版本会临时修改 Grok EXE 的单个 Inspector fuse 字节，不修改 `app.asar`、其他 fuse、快捷方式或用户数据。
- 临时修改期间 EXE 的 Authenticode 签名失效；Grok 完全退出并还原原始字节后恢复有效。运行中的 EXE 受 Windows 锁定，不能提前恢复磁盘文件。
- 恢复数据位于 `%LOCALAPPDATA%\GrokBackgroundStudio\fuse-recovery`，请勿在事务未完成时删除备份、记录或助手。
- 助手不是系统服务；断电或助手也被终止后，下次启动插件继续恢复，不保证插件未运行时立即恢复。
- 安装后通过宿主重新应用背景。建议同时升级 Background Studio v0.3.5，避免旧宿主误提示反向更新。

## 验证

- 68 项常规 Rust 测试、4 项实机集成测试、5 项脚本测试通过。
- 图片/视频、隐藏窗口、暂停/重启用、刷新恢复、普通启动自动接管、官方外观恢复及崩溃恢复已实机验收。
- 退出后 EXE SHA-256 与原版完全一致，数字签名为 `Valid`。完整记录见 `docs/0.3.7-verification.md`。
