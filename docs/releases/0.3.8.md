# Grok Bot Background Studio v0.3.8

## 修复

- 修复运行中三个点活动提示后面的深色矩形和横向暗带。同时覆盖紧凑文字提示 `sand-activity-line` 与整行图标提示 `sand-activity-mark`，不再误套用普通消息卡片底色；直接透出已配置的聊天背景，保留状态文字、圆点及动画。
- Cursor 任务卡片 `sand-cursor-agent-card` 接入现有「卡片不透明度」设置，不再保留官方不透明底色。标题、完成标记和「在 Web 中打开」按钮不随底色一起变淡。
- 所有新样式仅在背景启用时生效，停用后恢复官方外观；普通消息卡片的透明度设置不受影响。

## 验证

- 新增活动提示双形态与 Cursor 卡片透明度回归测试。
- 在 Grok Bot 0.57.1 的实际页面验证整行活动提示透明、Cursor 卡片跟随当前 35% 不透明度设置。
- 浏览器验证卡片不透明度从 35% 切换到 90%、两种活动提示保持透明，以及停用后恢复官方底色。

保留 v0.3.7 的 Grok 0.57.1 兼容与退出恢复机制；本版不改变 fuse 处理策略和用户设置。可在 Background Studio 宿主中检查更新并安装。
