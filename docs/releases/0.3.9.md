# Grok Bot Background Studio v0.3.9

## 修复

- Grok 提问/选择卡片（带 A/B 选项的确认卡片）接入「卡片不透明度」设置，覆盖待回答、已回答和已关闭三种状态。
- 清除卡片内部选项列表重复叠加的实底色，仅在卡片局部重设背景变量，避免影响其他组件。
- 保留文字、选项边框、悬停、选中、禁用及键盘焦点样式，不更改回答、关闭或快捷键行为。
- 新样式仅在背景启用时生效，停用后恢复官方外观。

## 验证

- 新增选择卡片透明度与局部变量回归测试。
- 使用 Grok 官方 CSS 在隔离浏览器节点中验证三种卡片状态、0% / 35% / 90% 不透明度、停用恢复，以及卡片外部组件不受影响。
- 本地补丁已加载到实际 Grok 会话，用户确认效果正常。

本版保留 v0.3.8 的活动提示与 Cursor 任务卡片修复，不改变用户设置或 fuse 恢复机制。可在 Background Studio 宿主中检查更新并安装。
